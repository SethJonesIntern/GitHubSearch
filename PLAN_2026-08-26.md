## Why this exists

The session started from one question: *why do only 81% of analyzed applications contain
an LLM call site?* The answer turned out not to be about LLM applications at all — the
denominator has ~100 un-triaged repos in it that a junk search token dragged in
(`getmoto/moto`, `Pylons/pyramid`, `mongodb/motor`, `NVFlare`, two Ansible collections,
~18 diffusion-model papers). **81% is a denominator artifact.** Cleaning it moves the
figure to ~92% without touching a single measurement.

That is CLAUDE.md's known open item #3 ("109 repos are undecided"), reached from the
other direction. Scope in this pipeline is **opt-out**: `pipeline/cuts.py` reads a
hand-edited `in_scope` column, so anything nobody has reviewed is counted by default.
